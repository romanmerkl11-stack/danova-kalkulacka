# Daňová kalkulačka SZČO

Offline kalkulačka dane z príjmov a odvodov (SP, ZP) pre živnostníkov s paušálnymi výdavkami. Neskôr pribudne verzia pre s.r.o.
Všetky výpočty a dáta zostávajú v počítači. Na internet ide appka len s vaším dovolením.

Stav vývoja a ďalšie kroky sú v [HANDOFF.md](HANDOFF.md), detailný plán v [docs/PLAN.md](docs/PLAN.md).

```bash
npm install
npm test
```
